# 🎓 Student Management System

A **Student Management System** developed using **Python and Tkinter** to efficiently manage student information through a simple and user-friendly graphical interface.

## 📌 Project Overview

The Student Management System helps administrators manage student records digitally. It provides features for adding, viewing, searching, updating, and deleting student information.

The application also includes an **Admin Login, Dashboard, and CSV Export** functionality.

## 🚀 Features

* 🔐 Admin Login
* 👨‍🎓 Add Student
* 📋 View Student Records
* 🔍 Search Student
* ✏️ Update Student Details
* 🗑️ Delete Student
* 📊 Dashboard
* 📁 Export Student Data to CSV
* ✅ Input Validation
* 💾 JSON-based Data Storage
* 🖥️ User-friendly Tkinter GUI

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – GUI development
* **JSON** – Data storage
* **CSV** – Data export
